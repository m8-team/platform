# M8 JSON Render Module SDK

## Responsibility

Defines the stable contracts and construction helpers shared by independently packaged M8 UI modules and the Console composition root.

## Exports

- `defineModule` and `ModuleDefinition`
- `defineQuery` and `QueryDefinition`
- `defineOperation` and `OperationDefinition`
- json-render route and access contribution types

## Does Not Own

- Business module routes or API clients
- Console module discovery and composition
- React component renderers
