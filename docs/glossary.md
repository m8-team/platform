# Глоссарий

| Термин | Значение в документации |
| --- | --- |
| M8 Platform | Монорепозиторий и разрабатываемая платформа |
| SDD | Spec-Driven Development: разработка от согласованного описания поведения |
| Модуль | Область ответственности; не обязательно отдельный развёртываемый сервис |
| Функция (feature) | Законченная возможность системы, описываемая одной спецификацией |
| Спецификация | Требования, поведение и сценарии приёмки в `spec.md` |
| План | Технический способ реализации в `plan.md` |
| Задачи | Проверяемые шаги реализации и проверки в `tasks.md` или issue |
| Инвариант | Условие, которое должно сохраняться в указанной области действия |
| ADR | Architecture Decision Record: запись значимого архитектурного решения |
| Контракт API | Исходное описание интерфейса в `api/proto/` |
| Арендатор (tenant) | Граница изоляции данных и действий; соответствие предметным сущностям ещё не определено |
| Организация | Предлагаемая сущность Resource Manager; детали иерархии открыты |
| workspace | Рабочее пространство в ответственности Resource Manager; отношения с организацией и проектом открыты |
| Проект | Предлагаемая сущность Resource Manager; жизненный цикл требует уточнения |
| Идентичность (identity) | Представление субъекта в Identity; виды субъектов ещё не определены |
| Профиль | Связанные с идентичностью сведения; состав и владение полями открыты |
| Аутентификация (authentication) | Подтверждение личности |
| Authentication challenge | Шаг подтверждения личности; виды и жизненный цикл открыты |
| Авторизация (authorization) | Определение допустимости действия субъекта над ресурсом |
| Роль | Предлагаемая сущность Access для описания прав; семантика открыта |
| Назначение | Предлагаемая связь предоставления доступа; семантика открыта |
| Отношение доступа | Связь, учитываемая Access при проверке разрешений; модель открыта |
| Идемпотентность | Повтор операции не приводит к дополнительному эффекту в определённых спецификацией условиях |
| Issue | Запись в трекере задач |
| PR | Набор изменений для ревью |
| Draft / Accepted / Implemented / Deprecated | Статусы спецификации, определённые в правилах версионирования |

Используйте эти термины последовательно. Новые предметные значения уточняйте до включения в требования; исходные предложения не являются утверждённой моделью.
