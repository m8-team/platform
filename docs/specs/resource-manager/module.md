# Resource Manager

Технический идентификатор: `resource-manager`.
Состояние описания: исходное предложение. Границы и интеграции не подтверждены командой.

## Ответственность

Организации, workspace и проекты, их жизненный цикл.

Подтверждение личности и вычисление разрешений предлагается относить к Authentication и Access соответственно. Разделение уточняется вместе с [границами модулей](../../architecture/module-boundaries.md).

## Общие инварианты

Подтверждённые предметные инварианты модуля пока не определены. Их следует уточнить в ходе первой затрагивающей модуль функции и зафиксировать здесь с областью действия и основанием.

Применяются [общие принципы платформы](../../principles.md) и [глоссарий](../../glossary.md). Открытые вопросы ниже не являются требованиями.

## Взаимодействия

Связь с Access для проверки разрешений над ресурсами и реакции на изменение их жизненного цикла остаётся открытым решением. Способ взаимодействия, события и поведение при сбоях не выбраны.

## Открытые решения

- Как связаны организация, workspace и проект; допустимы ли перемещения и изменение иерархии?
- Какие состояния жизненного цикла, правила удаления и восстановления нужны?
- Как сущности соотносятся с арендатором и границей изоляции?
- Какие данные принадлежат модулю и какие изменения должны быть атомарными?
