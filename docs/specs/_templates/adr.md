Новый ADR всегда начинается со статуса 🟡 **Proposed**. Шаблон не утверждает решение. Используйте [правила ADR](../../adr/README.md). Готовый ADR размещается в `docs/adr/{number}-{short-name}.md`; после переноса пересчитайте относительные ссылки.

Для единообразного отображения используйте следующие статусы:

| Статус | Когда использовать |
| --- | --- |
| 🟡 **Proposed** | Решение предложено и ещё не согласовано. |
| 🟢 **Accepted** | Решение явно согласовано; в поле «Подтверждение согласования» укажите ссылку на фактическое подтверждение. |
| 🔴 **Rejected** | Предложение рассмотрено и отклонено. |
| ⚫ **Deprecated** | Решение больше не рекомендуется к использованию, но не обязательно заменено другим ADR. |
| 🟣 **Superseded** | Решение заменено новым ADR; укажите ссылку на заменяющее решение. |
